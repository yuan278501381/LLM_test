# 项目级工程经验法则 (Lessons Learned)

> 从 M10~M15 全量开发与三轮独立审计中提炼，所有 Agent 必须遵守。

## 🔴 P0 致命红线

### 1. 禁止伪梯度
任何声称"训练"或"优化"的代码，参数更新必须来自对损失函数的真实解析梯度（如 Softmax 残差 P-Y 反向传播），绝不允许用 `np.random.randn` 等随机扰动冒充梯度。验证方法：连续 20 步训练后 Loss 必须单调下降。

### 2. 禁止合成假数据冒充真实计算
当 UI 声称展示"模型训练损失"时，数据必须来自引擎的实际调用返回值，禁止用 `np.exp(-0.08 * ep)` 等手写公式生成假收敛曲线。审查方法：追溯图表数据源是否为模型方法的返回值。

### 3. 算法必须在实际使用参数下有效
当教学演示使用极端参数（如扩散步数 T=20）时，必须验证算法在该参数下仍满足数学前提。不能仅在论文默认参数（如 T=1000）下测试就认为有效。验证方法：在实际 min/max 边界值上检查物理含义。

## 🔄 架构与测试红线

### 12. Streamlit 依赖模块热重载与 CI 进程生命周期差异防范
1. **生命周期差异本质**：本地 CI/CD（`pytest`）每次均在全新干净的 Python 进程中启动，能够导入最新代码；而用户的 Streamlit 服务通常在后台长期运行，其内置的热重载仅监听 `pages/*.py`，**不会自动刷新已缓存在 `sys.modules` 中的二级依赖包（如 `nn_core/*.py`）**，从而导致 `ImportError: cannot import name ...`。
2. **防御性架构设计**：必须在全站通用的页面初始化切面（如 `apply_custom_theme()`）中注入动态模块热刷新机制（`importlib.reload`），确保用户在浏览器端切换或刷新页面时，始终无感同步最底层算法引擎的符号导出，无需手动重启服务器。
3. **E2E 冒烟测试全覆盖**：CI 测试中必须包含针对所有页面的完整生命周期 AppTest 仿真（`test_dashboard_ui.py`），确保全站 15 个页面从导入到交互按钮 100% 可执行。

## 🟡 P1 常见陷阱

### 4. 函数命名必须精确匹配计算语义
函数名的每个词必须与返回值的数学含义严格对应。返回标量不能叫 "vector"，返回幅度不能叫 "field"。命名审查：函数名暗示的数据结构是否与返回值的 shape/dtype 一致？

### 5. 方向性描述必须与数学定义交叉验证
涉及梯度方向、边缘方向、轴向的文字描述，必须回到算子的卷积核矩阵手算验证。人类直觉在 X/Y 方向上极容易搞反（如 Sobel-X 检测垂直边缘而非水平边缘）。

### 6. UI 显示数值禁止硬编码
当展示值（如"窗长 23.2ms"）与可调参数（如 n_fft、采样率）有函数关系时，必须用 f-string 动态计算。全局搜索 UI 代码中的纯数字字面量，检查是否应由变量动态生成。

### 7. 同一模块内数学符号约定必须统一
行向量 vs 列向量、左乘 vs 右乘的约定必须全文一致。如果 forward 使用 `h = x @ W`（行向量右乘），docstring 不能写 `h = Wx`（列向量左乘）。

## 🟢 P2 细节精益

### 8. 注释中的数值常量必须与运行值一致
注释 `# ~0.569` 时代码实际值必须约为 0.569。用 `python -c` 验算所有带有 `# ~数字` 注释的行。错误注释比无注释更危险。

### 9. 边界条件 max/min 必须检查等值点
写 `max(1, x - y)` 时必须问：当 x == y 时应该发生什么？如果答案是"什么都不做"，就应该是 `max(0, x - y)`。

### 10. 关键交付物必须跨 Agent 独立交叉验证
实现完成后必须由不同模型/Agent 逐行代码审查与数值验算。审查必须包含 `python -c` 关键中间值验算，不能仅依赖测试通过。对声称"已修复"的代码，验收时必须读实际代码而非信任声明。

## 🎨 UI 视觉红线

### 11. 严禁滥用廉价感彩色 Emoji (Professional World-Class UI)
世界级专业产品与开源顶级项目严禁在页面标题、卡片标题、Tab、按钮和核心度量中使用廉价感彩色 Emoji（如 🚀, 📖, 📊, 🎯, ⚡, 💡, ⚠️ 等）。必须统一采用高质感专业设计语言：
1. **统一图标规范**：使用内置的专业 SVG 矢量线框图标系统（`styles.icons` / Feather / Lucide 规范，如 `render_icon("activity")`）；
2. **极简专业标牌**：使用大写双斜杠国际化排版（如 `[GROWTH GUIDE // 成长指南]`、`[HOW TO READ // 读图指南]`、`[TELEMETRY]`、`[MATHEMATICS]`、`[CRITICAL // 关键注意]`、`[TIP]`）；
3. **视觉一致性**：保持科技感、极客感与高保真专业学术气质。
